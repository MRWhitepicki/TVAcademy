# TV ACADEMY — стартовая версия

Статический учебный сайт на чистых HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в браузере. Для публикации на GitHub Pages загрузите все файлы репозитория и включите Pages для ветки `main`, папки `/root`.

## Что уже работает
- обязательный ввод имени и редактирование профиля;
- сохранение имени, прогресса, статистики и результатов в LocalStorage;
- главная панель и навигация;
- 12 учебных направлений с базовыми материалами;
- каталог с отдельными карточками модификаций;
- сравнительные таблицы технологий;
- экзамены с 4 уровнями, 10 вопросами, обратной связью и итоговым разбором;
- тренажёр возражений и энциклопедия терминов;
- адаптивная вёрстка для телефона и компьютера.

## Важные замечания к наполнению
Это рабочий первый каркас, а не завершённая коммерческая база моделей. В каталоге намеренно нет выдуманных официальных фотографий. Визуалы телевизоров сейчас являются нейтральными CSS-макетами и явно обозначены как заглушки. Для финального каталога нужно подставить точные официальные изображения каждой диагонали и отдельно сверить характеристики каждой модификации по источникам производителя.

## Структура
- `index.html` — разметка приложения
- `styles.css` — оформление и адаптивность
- `app.js` — навигация, данные, обучение, экзамены и LocalStorage
